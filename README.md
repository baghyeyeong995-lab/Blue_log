# BLUE LOG 멀티플레이어

닉네임과 캐릭터를 고른 뒤 **같은 주소**로 접속하면 같은 바다에 있는 사람들을 볼 수 있습니다. 다른 캐릭터를 클릭하면 해당 사람의 게임 시뮬레이션 잠수/휴식 기록이 나옵니다.

## 로컬 실행

Node.js 20+ 설치 후 폴더 안에서:

```bash
npm install
npm start
```

브라우저로 http://localhost:3000 을 엽니다. 다른 기기에서 테스트하려면 서버 컴퓨터의 같은 Wi-Fi 내부 IP와 3000 포트로 접속합니다.

## 인터넷 공개

Render 등의 Node.js 웹 서비스에 이 프로젝트를 올리고 `npm install`, `npm start`를 사용합니다. HTTPS/WSS가 설정되는 배포 URL을 친구들에게 공유하세요. 정적 파일만 Netlify에 올리면 **실시간 멀티플레이는 동작하지 않습니다.**

서버 기본 저장 방식은 `profiles.json` 파일이므로 영구 디스크가 없는 무료 서버에서는 재시작/재배포 시 서버 기록이 소실될 수 있습니다. 실서비스는 영구 볼륨을 연결하고 `DATA_PATH=/data/profiles.json`을 지정하거나 DB를 연결해야 합니다. 같은 브라우저 프로필을 다른 기기에서 자동으로 이어받지는 못합니다.

## 보안과 제한

* 닉네임은 로그인 신원이 아니며 브라우저에 생성한 임의 토큰으로 프로필을 구분합니다. 기기/브라우저 데이터 삭제 시 계정 복구는 불가합니다.
* 다른 이용자가 나의 시뮬레이션 연습기록을 조회할 수 있습니다. 실명/민감한 정보를 닉네임으로 넣지 마세요.
* 서버는 다른 이용자의 기기에서 생성된 기록을 검증하지 않습니다. 실제 생리학적 숨참기 기록이나 실제 수심을 측정하는 기능이 아닙니다.
* 보안 강화가 필요한 공개 운영에서는 로그인, 이용자 차단, 데이터 삭제/내보내기 및 운영자 신고 기능을 추가하세요.
